## Featured Projects

### [Smart FAQ Hybrid Retrieval System](https://github.com/HadisArefanJazi/smart-faq-rag-search)

Hybrid FAQ retrieval system combining BM25 sparse search and SentenceTransformer dense embeddings, with CrossEncoder reranking, score-based fallback, source provenance, and Recall@K/MRR evaluation.


### [Adaptive Human-in-the-Loop LLM Agent with Reinforcement Learning](https://github.com/HadisArefanJazi/adaptive-human-in-the-loop-llm-agent)

PyTorch DQN agent that learns when to answer directly, retrieve evidence, use a tool, or ask a human under accuracy and resource constraints.


### [Student Enrollment AI Assistant](https://github.com/HadisArefanJazi/student-enrollment-api-chatbot)

LLM-powered assistant that uses LangChain tool calling to query a FastAPI backend and return grounded student enrollment information from structured data.
